# Book Finder

A complete React + Tailwind CSS Book Finder app (Take-Home Challenge submission).

## What is included
- React app (Create React App structure)
- Tailwind CSS setup (tailwind.config.js + postcss.config.js)
- Components: App + BookCard
- README with run & deploy instructions
- .gitignore

## Run locally
1. `npm install`
2. `npm start`
3. Open http://localhost:3000

## Build
`npm run build`

## Deploy to Vercel
1. Push repo to GitHub
2. Sign in to Vercel and import the repository
3. Vercel auto-detects Create React App. Click Deploy.

## API
Uses Open Library Search API:
`https://openlibrary.org/search.json?title={bookTitle}`
